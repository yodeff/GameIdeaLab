# 効果音

アプリの効果音（design/03 §2.7）。すべてこのプロジェクトのために生成したもので、既存の音素材は使っていない。

- 生成: Stable Audio 3（medium、手元の PC で実行）。2026-11-05
- 加工: 切り詰め・モノラル化（complete・fanfare 以外）・ピークを -3 dBFS にそろえる・Ogg Vorbis（48 kHz、品質 0.5）。roll は 150 ms の重ね合わせでつなぎ目のないループにした
- 公開の前に、生成モデルの利用条件（生成した音を OSS に入れて配ってよいか）を確かめる（STATE の U-8）

| ファイル | 使うとき | 生成の指示（要約） | seed |
|---|---|---|---|
| `roll.ogg` | 抽選中（ループ） | 福引きのガラガラ（木の抽選器に小さな玉）が一定の調子で回り続ける。乾いた木の音、近くで、残響なし | 2105570400 |
| `stop.ogg` | スロットが 1 つ止まった | 木の玉が抽選器から木の受け皿に落ちる短い「コトン」 | 993436747 |
| `decide.ogg` | 組み合わせが決まった（`fanfare.ogg` と重ねる） | 福引きの係が大当たりを知らせる大きな真鍮の鐘を勢いよく振る | 2147338689 |
| `fanfare.ogg` | 組み合わせが決まった（`decide.ogg` と重ねる） | 景品が当たったときの短いファンファーレ。金管の「タ・タ・ターン」から長調の和音、シンバルとティンパニ | 103040792 |
| `complete.ogg` | 案が出そろった | 景品の発表の短いジングル。グロッケンと弾いたシンセの上がる長調の分散和音、太鼓なし | 500512899 |

指示の全文と加工の手順は、生成時の記録（`.json`）として `private/sound-candidates/` に残している（公開しない）。
