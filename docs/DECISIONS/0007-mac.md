# 0007: Mac にも配る（dmg・アドホック署名・GitHub Actions で作る）

- 状態: 採用（2026-11-05）。Mac の実機での確かめはまだ
- 関連: DECISIONS/0006（配布の形）、STATE の Q-15、docs/RELEASING.md

## Context

メンテナーから「Mac にも対応できますか？」「GitHub Actions で作れますか？」。Electron のアプリなので作りの大部分（SQLite、safeStorage はキーチェーン、Sign in with ChatGPT の loopback、窓を閉じたときの動き）はそのまま動く。直す必要があったのは、キー操作（Ctrl 固定）、Mac のメニュー（「編集」が無いと入力欄で ⌘C・⌘V が効かない）、書体（Windows の書体だけを並べていた）。

Mac 用の dmg は Mac の上でしか作れない。手元は Windows だけで、Mac の実機も無い。

## Decision

- 画面のキー操作は、Mac では ⌘、ほかでは Ctrl を主な修飾キーにする（`src/renderer/src/keys.ts`）。表示も「⌘S」「⇧⌘C」と「Ctrl+S」「Ctrl+Shift+C」を分ける。
- Mac では標準のメニュー（アプリ・編集・ウィンドウ）を置く。Windows は今までどおり。
- 書体に `-apple-system`・ヒラギノを足す。
- 配布は dmg（Apple Silicon と Intel を別々に）。証明書は使わず**アドホック署名**だけをする（`identity: '-'`、`hardenedRuntime: false`）。署名が無いと Apple Silicon の Mac で「壊れているため開けません」と出て開く手段が無くなるため。公証はしない。
- 作るのは GitHub Actions の Mac の環境（`macos-latest`）。Release のワークフローで Windows と Mac を並べて作り、1 つの下書きにまとめる。CI も Windows と Mac の両方で検査とビルドを通す。

## Alternatives

- Apple Developer Program（年 99 ドル）で署名と公証をする: 警告が出なくなるが費用がかかる。利用者の負担が問題になってから考える。
- Universal（1 つの dmg に両方）: ファイルが大きくなる。別々にした。

## Consequences

- 利用者は初回、「開発元を確認できない」の警告から「システム設定 → プライバシーとセキュリティ → このまま開く」で開く（README に書く）。
- 保存データは `~/Library/Application Support/Game Idea Lab`。トークン・API キーはキーチェーンの鍵で暗号化する（safeStorage）。アドホック署名なので、版を入れ直したときにキーチェーンへの許可を聞かれることがある。
- Mac の実機で起動・抽選・サインイン・生成・保存を確かめるまでは「試験的」として扱う（06-manual-checks の Mac の節）。
