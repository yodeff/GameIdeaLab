# STEP 3 設計 (2) 画面

- 作成: 2026-11-05
- 前提: 企画書 §11、[STEP 1](01-requirements.md) の D-番号、[アーキテクチャ](02-architecture.md)
- 方針: 起動したらすぐ回せる。画面は 3 つ（メイン・保存済み・設定）とモーダルだけ。タブを増やさない（企画書 §11.1）。

## 1. 画面の一覧

| 画面 | 開き方 | 中身 |
|---|---|---|
| メイン | 起動時 | 3 つのスロット、一括抽選、A/B モード |
| 保存済み | ヘッダーの「保存済み」 | アイデアの一覧と詳細、検索・絞り込み、出力 |
| 設定 | ヘッダーの歯車 | AI の接続、生成の既定値、見た目 |
| アイデアの詳細（モーダル） | カードの「詳細」 | 全項目、メモ、操作 |
| カテゴリの選択（ポップオーバー） | スロットのカテゴリ表示 | 複数選択のチェック |

## 2. メイン画面

### 2.1 配置（幅 1280 のとき）

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Game Idea Lab                    [ A 自分で考える | B AI に考えさせる ]   保存済み  ⚙ │
├──────────────────────────────────────────────────────────────────────┤
│  ┌ ジャンル ──────── × ┐ ┌ キーワード 1 ──── × ┐ ┌ キーワード 2 ──── × ┐ │
│  │ すべて            ▾ │ │ モノ・道具 ほか 1  ▾ │ │ すべて            ▾ │ │
│  │                      │ │                      │ │                      │ │
│  │  経営シミュレーション │ │     自動販売機        │ │        寄生          │ │
│  │                      │ │                      │ │                      │ │
│  │  ↻ 引き直す 🔓 固定 ✎ │ │  ↻ 引き直す 🔒 固定 ✎ │ │  ↻ 引き直す 🔓 固定 ✎ │ │
│  └──────────────────┘ └──────────────────┘ └──────────────────┘ │
│ ＋ ジャンル 1/3     [  ⟳ 回す  (Space)  ]   組み合わせをコピー     ＋ キーワード 2/5 │
├──────────────────────────────────────────────────────────────────────┤
│  （下部: A モード または B モード。§2.3・§2.4）                               │
└──────────────────────────────────────────────────────────────────────┘
```

- アイコンは SVG で描く（絵文字は図の説明のため）。
- スロットの数は変えられる（DECISIONS/0005）。ジャンルは 0〜3（初期 1）、キーワードは 1〜5（初期 2）。ジャンルを左、キーワードを右に並べる。
- 「＋ ジャンル」「＋ キーワード」は回すボタンの左右に置き、今の数と上限を出す。上限なら押せない。スロットの右上の × で外す（下限なら出さない）。
- ジャンルが 0 のときは、ジャンルの位置に「ジャンル自由」の札（AI がキーワードに合うジャンルを選ぶ、の説明と「＋ ジャンルを足す」）を置く。
- スロットは幅 168px 以上で折り返して並べる。スロットが狭い（270px 以下）ときは、操作の文字を隠してアイコンだけにする。

### 2.2 スロット

| 要素 | 振る舞い |
|---|---|
| カテゴリの表示 | 選んだカテゴリの先頭の名前と「ほか N」。押すとポップオーバーで複数選択。何も選ばなければ「すべて」（D-1）。ジャンルは親カテゴリ単位（D-6） |
| 語 | 大きく表示。長い語は縮小して 1 行に収める |
| ↻ 引き直す | このスロットだけ抽選する。固定中でも引き直せる（固定は一括抽選から守るためのもの） |
| 🔒 固定 | 一括抽選で変えない。固定中は枠の色と鍵のアイコンで常に分かるようにする（企画書 §11.4） |
| ✎ 手動入力 | その場で入力欄になる。Enter で確定し、自動で固定する（D-4）。Esc で取り消し |

### 2.3 下部: A モード（自分で考える）

```text
┌ この組み合わせでどんなゲーム？ ─────────── 書き始め: 自動販売機 × 寄生 × 経営シミュ… ┐
│ タイトル（任意）                                                                │
│ ┌───────────────────────────────────────────────────────┐ │
│ │ 自由に書く                                                                │ │
│ └───────────────────────────────────────────────────────┘ │
│  自動保存済み                                         [ 保存 (Ctrl+S) ]  [ 消す ] │
└────────────────────────────────────────────────────────────┘
```

- 下書きは自動で保存し、再起動しても残す（D-9）。
- 再抽選しても下書きは消さない。下書きを書き始めたときの組み合わせと今の組み合わせが違えば、見出しの横に「書き始め: …」を出す（D-10）。保存するときは、書き始めの組み合わせと今の組み合わせのどちらで保存するかを選べる（初期は今の組み合わせ）。
- AI の案はこのモードでは出さない（企画書 §6.1）。

### 2.4 下部: B モード（AI に考えさせる）

```text
┌──────────────────────────────────────────────────────────────┐
│ [ ✦ 3 案を生成 (Ctrl+Enter) ]  案の数 [3▾]  忠実度 [標準▾]   Using ChatGPT plan · Manage usage │
├──────────────────────────────────────────────────────────────┤
│ ┌ 王道 ─────────────┐ ┌ 変化球 ───────────┐ ┌ 実験的 ───────────┐ │
│ │ 寄生自販機チェーン     │ │ 他社自販機におじゃま… │ │ 歩く自販機の飼い方     │ │
│ │ 一言のコンセプト       │ │ …                    │ │ …                    │ │
│ │ コアループ（2 行）     │ │                      │ │                      │ │
│ │ ☆  保存  コピー  詳細  派生▾ │ │                      │ │                      │ │
│ └──────────────────┘ └──────────────────┘ └──────────────────┘ │
│ 自動販売機 × 寄生 × 経営シミュレーション で生成（14:02）                         │
└──────────────────────────────────────────────────────────────┘
```

| 状態 | 表示 |
|---|---|
| 未接続 | カードの代わりに「B モードには AI の接続が必要です」と「Continue with ChatGPT」のボタン、設定への案内。A モード・抽選はそのまま使える |
| 生成中 | 案の数だけ骨組みのカードを並べ、届いた案から中身を入れる。経過秒数と「中止」。抽選・A モード・保存済みは使える（企画書 §11.4、D-16） |
| 完了 | 案のカード。上に生成したときの組み合わせと時刻（組み合わせを変えても前の結果は残る） |
| 誤り | 種類ごとの文言と操作（§5） |

- 直前の生成結果は、再抽選しても次の生成までは表示し続ける。それより前の結果は保存済み画面の「履歴」で見る。
- 「派生▾」は「もっと独創的に」「ゲーム性を強く」「もっとシンプルに」「別のジャンルで」「自由に指示…」。派生案は新しいカードとして元のカードの後ろに足し、「← 寄生自販機チェーン から」と元を示す（企画書 §8.3）。

### 2.5 操作の手早さ

| キー | 操作 | 有効な場所 |
|---|---|---|
| Space | 一括抽選 | 入力欄にカーソルが無いとき |
| 1〜9 | 左から数えてそのスロットだけ引き直す | 同上 |
| Shift + 1〜9 | 固定の切り替え | 同上 |
| Ctrl + Enter | 生成（B） | メイン画面 |
| Ctrl + S | 保存（A） | メイン画面 |
| Ctrl + Shift + C | 組み合わせをコピー | メイン画面 |

### 2.6 抽選の演出

- 回すと、固定していないスロットの語が約 0.3 秒、辞書の語で入れ替わってから止まる。スロットごとに少しずつ遅れて止まる（左から）。
- 連打したら演出を飛ばしてすぐ結果を出す。`prefers-reduced-motion` のときは演出しない。
- 演出の間も結果は先に決まっている（演出は見た目だけ）。

### 2.7 効果音（2026-11-05、メンテナーの要望）

| とき | 音 |
|---|---|
| 抽選中 | 回っているスロットが 1 つでもあれば、福引きの抽選器の「ガラガラ」をループで流す（毎回違う位置から）。スロットがいくつ回っても 1 本 |
| スロットが止まった | 1 つ止まるごとに、玉が受け皿に落ちる「コトン」 |
| 組み合わせが決まった | 全部が止まったらガラガラを止め、1 回だけ大当たりの鐘とファンファーレを重ねて鳴らす（約 2 秒）。次の抽選が始まったら消す。演出なし（動きを減らす設定・連打）でも鳴らす |
| 案が出そろった | 生成・派生が終わり、1 案以上届いたら短いジングル。中止・誤り・0 案では鳴らさない |

- 2026-11-05: 最初は Web Audio で作った電子音にしたが、メンテナー「もう少し抽選っぽい感じで」を受けて、audio-studio（Stable Audio 3）で作った音に替えた。出どころと生成の指示は `src/renderer/src/assets/sounds/README.md`。
- 2026-11-05: メンテナー「組み合わせが決まったときの音はもう少し大仰でいい」を受けて、決定の音を小さな鐘から「大きな鐘 + ファンファーレ」に替えた。
- 音は JS に埋め込み（`?inline`）、Web Audio で復号して鳴らす（Electron は `file://` で開くので `fetch` で読めない。LEARNINGS L-22）。5 つで約 160 KB。
- 設定の「音」で、オン・オフと音量（0〜100、初期 60）を変えられる。「試しに鳴らす」で確かめられる。初期はオン。
- 段取り（いつ何を鳴らすか）は `rollCues.ts` に分け、DOM なしでテストする。

## 3. 保存済み画面

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ← メイン   保存済み | 履歴     [ 検索…              ] ジャンル[すべて▾] ☆のみ □ │
├──────────────────────────┬───────────────────────────────────────────┤
│ □ ☆ 寄生自販機チェーン      │ 寄生自販機チェーン                      ☆  AI・王道  │
│     自動販売機 × 寄生 × 経営… │ 自動販売機 × 寄生 × 経営シミュレーション  11/05 14:02 │
│ □   他社自販機におじゃまします │                                               │
│ □   （A）冷蔵庫で育てる町     │ 一言 / 概要 / 操作 / 目的 / コアループ / 面白さの核 / │
│                              │ キーワードとゲーム性 / 任意の項目                    │
│                              │ メモ ┌─────────────────────────┐ │
│                              │      └─────────────────────────┘ │
│ 選んだ 2 件を Markdown で出力   │ コピー  Markdown で保存  派生▾  削除               │
└──────────────────────────┴───────────────────────────────────────────┘
```

- 「保存済み」と「履歴」（保存していない生成案。直近 200 件、D-17）を切り替える。履歴の案は「保存」で保存済みに移せる。
- 検索はタイトル・キーワード・ジャンル・本文・メモの部分一致（D-18）。
- A モードの案は本文（自由記述）をそのまま表示する。
- 削除は確認してから行う。元に戻す操作は作らない（保存済みの削除は取り消せないと確認の文言に書く）。

## 4. 設定画面

| 区分 | 項目 |
|---|---|
| AI の接続 | ChatGPT: 未接続なら「Continue with ChatGPT」。接続中ならアカウント（名前・メール）、「Using ChatGPT plan」・「Manage usage」、サインアウト。プラン利用が許可されていなければその旨と「もう一度許可する」 |
| | API キー（Q-4）: 「自分の OpenAI API キーを使う（利用料はあなたの OpenAI アカウントに課金されます）」を明示的に選んだときだけ入力欄を出す。保存後は末尾 4 文字だけ表示。削除 |
| | 使う接続: ChatGPT プラン / API キー（両方あるときだけ選べる。自動で切り替えない） |
| 生成 | モデル（`visibility == "list"` のもの。初期 `gpt-6.1-sol`）、案の数の既定（1〜10、初期 3）、忠実度の既定（厳格・標準・自由、初期 標準） |
| 見た目 | テーマ（システムに合わせる・ライト・ダーク） |
| データ | データのフォルダを開く、控えの場所 |

- 初めてプラン利用でサインインしたときだけ「You're using your ChatGPT plan」のモーダル（ChatGPT の設定で利用量を管理できることの説明、「Got it」）を出す（[調査 §7](../research/sign-in-with-chatgpt.md)）。

## 5. 誤りの表示

B モードの結果の場所に、1 行の説明と操作を出す。抽選・A モードには影響させない。

| `error.kind` | 文言の要点 | 主な操作 |
|---|---|---|
| `not-signed-in` | AI の接続が必要 | Continue with ChatGPT / 設定を開く |
| `plan-not-granted` | プランの利用が許可されていない | もう一度許可する |
| `not-eligible` | このアカウントはプランを使えない（Plus・Pro が対象） | 設定を開く（API キーの案内） |
| `usage-limit` | ChatGPT プランの利用量の上限に達した。回復の時刻は推測しない | Manage usage |
| `temporarily-unavailable` / `network` | 一時的に使えない・通信できない | もう一度 |
| `unsupported` | モデルや指定がこの接続で使えない | 設定でモデルを変える |
| `auth-failed` | 認証が切れた・接続が解除された | サインインし直す |
| `config-error` | アプリの設定の誤り（利用者には直せない） | 詳細をコピー |
| `incomplete` | 生成が途中で終わった | もう一度 |
| `cancelled` | 中止した（届いた案は残す） | — |

## 6. 見た目

- 色は CSS 変数で定義し、ライト・ダークを切り替える（今の `styles.css` を広げる）。強調色は 1 色。
- 固定中のスロットは強調色の枠と鍵。生成中のカードは控えめな明滅。
- 文字: Segoe UI / Yu Gothic UI。スロットの語は 28〜36 px、カードのタイトルは 18 px。
- 幅 1200 以上: スロット 3 列・カード 3 列。960〜1200: スロット 3 列・カード 2 列。最小幅は 960（ウィンドウの最小）。
- ウィンドウの大きさと位置を覚える（D-23）。
