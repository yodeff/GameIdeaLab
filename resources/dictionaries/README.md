### 流行・ネット語（`trend`）

2026-11 時点の新語・流行語の候補、若者言葉、ネットスラングから選んだ（出典は新語・流行語大賞や三省堂「今年の新語」のノミネート、JC・JK 流行語大賞など）。上の決まりに加えて、次は入れない。

- 属性（性別・国籍・障害・見た目・年齢層など）を貶める語、心の病や障害を揶揄する語
- 特定の人物・作品・キャラクター・商品に由来する語、曲名や歌詞そのもの
- 政治色の強い語、事件に結びつく重い語

「ドパガキ」程度の、行動を表す軽いスラングや自虐の語は入れる。流行語は古くなるので、年に 1 回ほど見直す。
