# 辞書

抽選に使う語の一覧。形式は `src/core/dictionary` の `KeywordDictionary`。決まりは [design/04 §1.3](../../docs/design/04-data-and-generation.md)。

## 一般キーワード（`keywords.ja.json`）

| id | カテゴリ | 語数 |
|---|---|---|
| `object` | モノ・道具 | 102 |
| `place` | 場所・施設 | 101 |
| `creature` | 生物・人物 | 102 |
| `action` | 行動・動作 | 104 |
| `nature` | 自然・現象 | 101 |
| `abstract` | 抽象概念 | 101 |
| `society` | 社会・制度 | 105 |
| `technology` | 技術・機械 | 98 |
| `culture` | 文化・娯楽 | 104 |
| `misc` | その他 | 107 |
| | 合計 | 1025 |

- 1 語は漢字・ひらがな・カタカナ・長音の 1〜10 文字。名詞か名詞化した動作。
- 入れない: 固有名詞・商標・作品名・実在の人物、差別的な語、性的な語。似すぎた語は片方だけ。
- 同じ語を 2 つのカテゴリに入れない。検査は `tests/core/dictionary.test.ts`。
- 既存の単語集は写さない（AGENTS.md §2）。

## ジャンル（`genres.ja.json`）

| id | 親カテゴリ | ジャンル |
|---|---|---|
| `action` | アクション系 | アクション、メトロイドヴァニア、ステルス、レース、リズムゲーム |
| `story` | 物語・探索系 | RPG、アドベンチャー、脱出ゲーム、ホラー |
| `strategy` | 思考・戦略系 | パズル、ストラテジー、タワーディフェンス、デッキ構築、オートバトラー、ローグライク |
| `management` | 経営・育成系 | シミュレーション、経営シミュレーション、育成ゲーム |
| `sandbox` | 創造・生存系 | サンドボックス、サバイバルクラフト |

「その他」は抽選の対象にしない（D-5）。
